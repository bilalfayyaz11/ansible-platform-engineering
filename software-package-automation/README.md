# Software Package Automation

This project demonstrates software installation and package lifecycle automation using Ansible on Red Hat Enterprise Linux compatible systems.

## What This Project Covers

- Automated package installation
- Package verification
- Package removal
- DNF package management
- Group-based host targeting
- Apache deployment automation
- Service management
- Idempotent infrastructure automation
